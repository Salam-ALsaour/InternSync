## Rules

- **Markdown is the source of truth.** Edit the `.md` files. The Word and PDF files of Projects 4 – 7 are generated from their Markdown on the course templates (see each folder's `build`); the other PDF and DOCX files are snapshots of earlier versions. None of them is edited by hand.
- **The Idea Form and the Proposal are frozen.** Later decisions go into the SPMP, SRS, design document, and [Change_Requests.md](Change_Requests.md).
- **Every requirement change is a change request:** add a CR entry, update the affected documents, and add a row to their revision history.
- **Diagrams** are edited in `InternSync_Diagrams/source/` and regenerated; see the [diagram pack README](InternSync_Diagrams/README.md).

## Final Submission

`Final_Submission/` holds the PDF of every maintained document and the SRS in Word and PDF on the course template. Rebuild it after a change:

```bash
python tools/trace.py && python tools/check_links.py      # requirements status and links
node tools/export_pdf.mjs                                  # PDFs (needs npm ci and Playwright's Chromium in frontend/)
```

The SRS Word and PDF files come from its own build ([Project_4_SRS/build](Project_4_SRS/build/README.md)).

## Exporting for Submission

Install pandoc once:

```bash
winget install --id JohnMacFarlane.Pandoc -e
```

The SRS is built on the course template with its own script; see [Project_4_SRS/build/README.md](Project_4_SRS/build/README.md).

For the other documents, from this `docs` folder, export to Word with pandoc (open the result in Word and save as PDF if a PDF is needed):

```bash
pandoc "Design/InternSync_Design.md" --resource-path="Design" -o "InternSync_Design_v1.3.docx"
```

`--resource-path` must point to the document's own folder so that the diagram images are found.
